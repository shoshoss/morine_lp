## 0. このファイルの目的

このファイルは、モリーヌLPに掲載する情報・原稿・口コミ・メニュー・写真の**唯一の正解（Single Source of Truth）**として使用する。

Codexおよび制作者は、既存HTMLや過去のチャットよりも本ファイルを優先する。

### v0.5での変更範囲(重要)

v0.4までは、ブランド戦略(ギャップ／見透かされる安心／強さの証明の3軸)を反映したものの、LP全体のセクション構成としては未整理な部分が残っていた。

本版では、以下の**11セクション構成**を最終形として確定する。

```
① ファーストビュー ………………………… 油断する
② 迷いの代弁 ……………………………… わかってくれてると感じる
③ 森さんという人(ギャップ) ……………… 驚く
④ 見透かされる体験 ……………………… 安心して身を委ねる
⑤ 強さの証明 ……………………………… 最後の不安が消える
⑥ メニュー・料金(悩み別入口) …………… 自分に関係あるものがあると気づく
⑦ 空間と仕組み(貸切・アクセス・着替え) … 現実的なハードルが下がる
⑧ お客様の声 ……………………………… 自分も同じ体験ができると確信する
⑨ 森さんからの言葉 ……………………… 人としての信頼が固まる
⑩ FAQ ……………………………………… 最後に残った疑問が消える
⑪ 予約導線 ………………………………… 行動に移る
```

あわせて、これまで共有されたすべての口コミ(ホットペッパー・GoogleMap含む全件)を精査し、各セクションの意図に最も合致する1件だけを選定した。個人情報保護のため、投稿者名は頭文字のみで表記する(旧v0.4のH-03〜H-08は本版で置き換え)。

### このファイルで管理するもの

- 店舗の確定情報
- 森さんが承認した内容
- 現在のメニュー・料金
- LPで使用する訴求
- LP掲載原稿
- 口コミ候補
- 写真素材と使用許可
- CTAと予約URL
- 未確認事項
- 使用しない表現

### 基本ルール

1. `[公開可]`の情報だけを公開画面に表示する
2. `[要確認]`は推測で補わない
3. `[非公開]`はLPへ使用しない
4. 情報が更新された場合は、HTMLより先に本ファイルを更新する
5. 古い情報を併記せず、更新履歴にだけ残す
6. 料金・クーポンは変更される可能性があるため、公開直前にも再確認する
7. 口コミは実在する一人の感想として扱い、複数人の内容を合成しない
8. 効果を保証する文章へ書き換えない
9. **口コミ投稿者は頭文字表記とし、実名・詳細な属性の掲載は行わない(v0.5追加)**

## 1. ステータス定義

| ステータス | 意味 | 公開画面 |
|---|---|---|
| `[公開可]` | 公式情報または森さんの確認済み | 表示可能 |
| `[口コミ根拠]` | 実在する口コミに基づく感想 | 口コミと分かる形で表示可能 |
| `[原稿案]` | LP向けに作成した文章案 | 公開前に最終確認 |
| `[要確認]` | 情報不足・条件未確認 | 表示しない |
| `[非公開]` | 使用不可・リスクが高い | 表示しない |
| `[管理用]` | 制作判断のための内部情報 | 表示しない |
