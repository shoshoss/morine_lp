## 制作背景

モリーヌは、広島・本通にある1対1のリラクゼーションサロンです。

制作前に店舗情報や実際のお客様の口コミを整理したところ、施術の力強さだけではなく、次のような点が繰り返し評価されていました。

- オーナーの柔らかく親しみやすい人柄
- 希望に合わせて調整される力加減
- 悩みをうまく説明できなくても、状態をくみ取ってもらえる安心感
- ほかのお客様を気にせず過ごせる貸切空間
- 初めてでも緊張が和らぐ接客
- 料金に対する納得感

そこで、店舗側が一方的に魅力を説明するのではなく、実際のお客様の体験を根拠として、初めての方が安心して予約できるLPを設計しました。

---

## 制作目的

- 初めて来店する方の心理的な不安を減らす
- オーナーの人柄と施術の特徴を伝える
- 利用者の悩みとメニューを分かりやすく結び付ける
- 実際のお客様の口コミを予約判断の材料として活用する
- ホットペッパービューティーへの予約導線を明確にする
- スマートフォンから快適に閲覧・予約できるようにする

---

## 想定したユーザーの不安

制作にあたり、初めて個人サロンを利用する方が抱きやすい不安を整理しました。

- 個人サロンへ行くのは少し緊張する
- 強めの施術を受けたいが、痛すぎないか心配
- 自分の悩みをうまく説明できるか分からない
- どのメニューを選べばよいか分からない
- 男性でも利用できるのか分からない
- 無理な勧誘や次回予約の強制がないか不安
- 店舗の場所や建物への入り方が分からない

これらの不安をFAQだけにまとめるのではなく、ページを読み進める中で段階的に解消できる構成にしています。

## コンセプト

### 「この人なら任せられそう」と感じてもらう

モリーヌの魅力は、料金や施術メニューだけではなく、オーナーの人柄と施術との組み合わせにあると考えました。

柔らかく親しみやすい人柄と、しっかりとした施術とのギャップを中心に、口コミ・コピー・写真・本人からのメッセージを組み合わせています。

価格だけで比較されるLPではなく、最終的に「この人に施術してもらいたい」と感じてもらえるページを目指しました。

## 情報設計

ページ全体を、利用者の感情が次の順番で変化するように設計しました。

1. ファーストビューで店舗の雰囲気を知る
2. 自分が抱えている悩みや迷いに気付く
3. オーナーの人柄と施術の特徴を知る
4. 希望をうまく説明できなくてもよいと分かる
5. 力加減に関する不安を解消する
6. 自分に合ったメニューを見つける
7. 貸切空間や営業時間などの利用条件を確認する
8. 実際のお客様の口コミから安心感を得る
9. オーナー本人からのメッセージを読む
10. FAQで最後に残った疑問を解消する
11. ホットペッパービューティーで空き状況を確認する

店舗情報を並べるのではなく、利用者の「不安・理解・納得・行動」が一本の流れとしてつながることを意識しました。

## 工夫した点

### 1．口コミを装飾ではなく、判断材料として活用

口コミをページの最後にまとめて掲載するだけではなく、それぞれの口コミが持つ役割を整理しました。

「人柄と施術のギャップ」「悩みをくみ取る対応」「力加減」「貸切空間の安心感」など、利用者が不安を感じるセクションの近くに、関連する口コミを配置しています。

店舗側の説明に加えて、実際に利用した方の体験を示すことで、情報の納得感を高めました。

### 2．メニュー名ではなく、利用者の悩みから選べる構成

施術メニューを単純に一覧表示するのではなく、次のような悩みを入口にしています。

- 首・肩・全身をしっかりほぐしてほしい
- 足の疲れや重さが気になる
- 頭や首まわりをゆっくり受けたい
- 複数のメニューを組み合わせたい

施術に詳しくない方でも、自分に合いそうなメニューを判断しやすい構成にしました。

### 3．限られた人物写真を、文章と口コミで補完

オーナー本人が写っている写真は多くないため、人柄を写真だけで表現しようとはしていません。

オーナーの穏やかな人柄については、実際のお客様の口コミ、語りかけるようなコピー、本人からのメッセージを組み合わせて伝えています。

一方、写真には次の役割を持たせました。

- 店内の清潔感を伝える
- 施術内容を視覚的に説明する
- しっかりと施術を行う印象を補強する
- 初めて来店する方に店内の様子を事前に伝える

素材の不足を無理に隠すのではなく、写真・文章・口コミの役割を分けることで、情報全体として店舗の魅力が伝わる設計にしました。

### 4．初めての方が迷わない写真付きアクセス

住所や地図だけではなく、建物入口から店舗の扉までを写真付きで掲載しました。

個人サロン特有の「建物に入りにくい」「どの部屋か分からない」という不安を、来店前に解消できるようにしています。

### 5．予約導線をホットペッパービューティーに統一

主要なCTAの遷移先をホットペッパービューティーに統一しました。

複数の予約方法を同じ強さで表示して利用者を迷わせるのではなく、「空き状況を確認する」という一つの行動を促しています。

### 6．スクロール後に固定予約ボタンを表示

ファーストビューの予約ボタンが画面内にある間は、画面下部の固定CTAを非表示にしています。

ファーストビューのCTAが画面外へ出た後に固定CTAを表示することで、予約ボタンが重複して見えることを防ぎながら、閲覧中に予約導線を見失わないようにしました。

JavaScriptの `IntersectionObserver` を使用し、スクロール位置に応じて表示を切り替えています。

### 7．スマートフォンを優先した設計

サロンを探す利用者がスマートフォンから閲覧することを想定し、モバイルでの使いやすさを優先しました。

- 読みやすい文字サイズと行間
- 指で押しやすいボタンサイズ
- 情報を把握しやすい余白
- 長文になりすぎない文章量
- 画面幅に合わせた画像のトリミング
- スクロール中も利用できる固定CTA

PC版では画面の広さを活かしながら、スマートフォン版と情報の優先順位が変わらないように調整しています。

### 8．誇張しない表現設計

リラクゼーションサロンであることを明確にし、医療行為と誤解される表現や、効果を保証する表現を避けました。

また、店舗からの説明とお客様個人の感想を区別し、口コミには個人差があることも明記しています。

## デザイン方針

清潔感や安心感を保ちながら、一般的なリラクゼーションサロンの柔らかい印象だけに寄りすぎないデザインを目指しました。

店内や施術中の手元を写した写真によって、空間の清潔感と、しっかりと施術を行う印象を伝えています。

一方、オーナーの穏やかな人柄については、写真だけに頼らず、実際のお客様の口コミや語りかけるようなコピー、本人からのメッセージを組み合わせて表現しました。

写真、文章、余白、タイポグラフィーにそれぞれ役割を持たせ、柔らかな人柄と本格的な施術とのギャップが、ページを読み進める中で伝わるように設計しています。

予約を強く迫るのではなく、利用者が不安を解消し、十分に納得したうえで行動できる落ち着いたトーンに統一しました。

## 実装時に意識したこと

### HTML

- 内容に合ったセマンティックな要素を使用
- 見出し階層を整理
- 画像に内容が伝わる代替テキストを設定
- JavaScriptが動作しない場合でも主要情報を確認できる構成

### CSS

- モバイルファーストのレスポンシブ設計
- CSSカスタムプロパティによる色や余白の管理
- 写真の比率を保った表示
- 予約ボタンの視認性と押しやすさを確保
- 過度なアニメーションを避け、内容の読みやすさを優先

### JavaScript

- `IntersectionObserver` を使用した固定CTAの表示制御
- ファーストビューのCTAと固定CTAの重複を防止
- 必要最低限の処理に絞り、ページ表示への影響を抑制

### 画像

- 用途に応じた画像サイズの調整
- WebP形式を中心に使用
- ファーストビュー以外の画像に遅延読み込みを設定
- `width` と `height` を指定し、レイアウトのずれを抑制
- `object-fit` を使用して端末ごとの表示を調整

## 制作上の課題と対応

### 課題

- オーナー本人の写真が限られていた
- 店舗の魅力を技術や料金だけで説明すると、他店との差が伝わりにくかった
- 口コミには魅力的な情報が多い一方、単純に並べるだけでは読み手に伝わりにくかった
- 個人サロン特有の心理的な不安があった

### 対応

- 人柄は口コミ・コピー・本人メッセージを中心に表現
- 写真は清潔感・施術・空間の説明に使用
- 口コミを内容別に分類し、関連するセクションへ配置
- 貸切空間、男性利用、着替え、勧誘、当日予約などの安心情報を明記
- 建物入口から店舗までを写真付きで案内
- CTAを一つの予約先へ統一

## 今後の改善

現在は公開までを完了していますが、予約率への影響はまだ計測していません。

今後は、次のデータを取得しながら改善する予定です。

- CTAのクリック数
- CTAの設置位置ごとのクリック率
- スマートフォンとPCの利用割合
- ファーストビューからの離脱状況
- メニューごとの閲覧・クリック状況
- ページの表示速度
- 実際の利用者や店舗オーナーからのフィードバック

数値をもとに、コピー、CTAの文言、配置、情報量などを継続的に改善していきます。

## 制作を通して学んだこと

本プロジェクトを通して、見た目を整えるだけでは、予約につながるLPにはならないことを学びました。

利用者がどこで不安を感じ、どの情報があれば安心できるのかを整理し、文章・写真・口コミ・デザイン・予約導線にそれぞれ明確な役割を持たせることが重要だと考えています。

また、理想的な写真素材がすべてそろっていない場合でも、素材の役割を整理し、口コミや文章で不足を補うことで、店舗の魅力を誠実に伝えられることを学びました。

デザインとコーディングだけでなく、顧客理解、情報設計、ライティング、実装、公開後の改善までを一つの流れとして捉えて制作しました。
