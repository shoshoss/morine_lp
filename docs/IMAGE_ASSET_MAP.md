## 1. 結論

- 店内、施術、着替え、アクセスの最低限の素材は揃っている。
- 現素材は 200 ～ 400px 幅が中心で、フル幅ヒーローには解像度が不足している。
- 初回公開は可能だが、売上最大化には高解像度の人物＋施術写真を 1 枚追加する価値が高い。
- LINE、旧営業時間・クーポン告知は、予約導線の競合や情報の陳腐化を避けるため初回 LP では使わない。

## 3. セクション別の推奨配置

### ファーストビュー

- 現素材だけで全幅写真を作らない。
- 暫定案：ロゴ＋コピーを主役にし、`therapist-body-treatment.webp`を小さな角丸写真として添える。
- 代替案：`salon-room.webp`を最大 640px 程度で表示し、暗いオーバーレイをかけず店内を自然に見せる。

### 特徴・施術者

- `therapist-body-treatment.webp`
- `body-treatment-full.webp`
- 口コミの「人柄」「しっかり圧」と近接配置する。

### 悩み別メニュー

- もみほぐし：`body-treatment-full.webp`
- ヘッド：`dry-head-spa.webp`
- フット：`foot-reflexology.webp`
- ハンド：`hand-reflexology.webp`
- 足湯・温熱は主メニューの後に小さく追加する。

### 初めての方・安心材料

- 貸切空間：`salon-room.webp`
- 着替え：`changing-room.webp`、必要なら`treatment-clothes.webp`
- オイル：`treatment-oils.webp`

### アクセス

1. `access-building.webp`
2. `access-corridor.webp`
3. `access-elevator-lobby.webp`
4. `access-room-202.webp`

`access-elevator-button.webp`は詳細説明を開いた場合だけ表示する。

## 4. 追加撮影の最優先

### 追加撮影 1：ファーストビュー

- 横長、最低 1600×1000px
- 森さんの表情が自然に分かる
- 実際の施術中で、手元の力強さも伝わる
- 利用者の顔は映さない、または使用許可を得る
- 明るい窓を背にしすぎず、顔と手元を適正露出にする

### 追加撮影 2：森さんの人物写真

- 縦または正方形、最低 1000px
- 店内で自然に微笑む
- 腕組みより、施術ベッド横に立つ構図

### 追加撮影 3：現行店内

- 現在のベッド配置が分かる横長写真
- ホットペッパーの「ベッド 1 台」表記と、既存写真に見えるベッド数の整合を確認する

## 6. 開発ルール

- HTML では実装用ファイル名だけを参照する。
- 画像の説明文をファイル名から自動生成しない。
- `width`と`height`属性を設定する。
- ファーストビュー以外は`loading="lazy"`を基本とする。
- `object-fit: cover`で重要な手元や顔が切れる場合は、画像ごとに`object-position`を設定する。
- 低解像度画像を CSS で大きく引き伸ばさない。
